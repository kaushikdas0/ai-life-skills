# excalidraw

## Summary
Excalidraw is an open-source virtual whiteboard for sketching hand-drawn style diagrams, wireframes, and flowcharts. It supports real-time collaboration with end-to-end encryption and runs entirely in the browser.

## Aliases
- excalidraw
- excalidraw whiteboard

## When to use
- Sketching diagrams, wireframes, or flowcharts quickly
- Collaborative whiteboarding sessions with live sharing
- Hand-drawn style visuals for docs, presentations, or brainstorming
- Quick visual prototyping without leaving the browser

## Setup
- No install needed — use at https://excalidraw.com/
- Self-host: clone repo, `npm install && npm run start`
- Embed in apps via the `@excalidraw/excalidraw` npm package

## Usage notes
- Drawings save in browser localStorage by default
- Export to PNG, SVG, or clipboard
- End-to-end encrypted live collaboration via shareable links
- Supports libraries of reusable shapes/elements
- MIT licensed — fully open source

## Caveats
- Browser storage can be cleared unexpectedly (use export as backup)
- Self-hosting requires Node.js environment
- Large canvases can slow down on low-end devices
