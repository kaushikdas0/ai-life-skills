# Skill Notes

Put one Markdown file here per Claude Skill.

## Naming

- Use lowercase hyphenated filenames when possible.
- File name should match the catalog entry slug.
- Example: `browser-automation.md`

## Required note fields

- Skill name
- What it does
- When to use it
- Official URL
- Source / repo URL if available; prefer adding the git repo when one exists because it makes install paths and source layout easier to find later
- Trigger phrases
- Setup / install notes
- Usage tips
- Caveats or gotchas
- Related skills

## Writing rules

- Put facts at the top.
- Put inferred details in a separate section or label them clearly.
- Keep the README index row short; keep details in the note file.
- If a public git repo exists, include it in the note and prefer it in the index when it is the most practical entry point.

## Template

Copy `skills/_template.md` for new entries.
