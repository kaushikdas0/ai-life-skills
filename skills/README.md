# Skill Notes

Put one Markdown file here per Claude Skill.

## Naming

- Use lowercase hyphenated filenames when possible.
- File name should match the catalog entry slug.
- Example: `browser-automation.md`

## Required note fields

- Skill name
- What it does
- When to use it
- Official URL
- Source / repo URL if available
- Setup / install notes
- Usage tips
- Caveats or gotchas

## Template

Copy `skills/_template.md` for new entries.
