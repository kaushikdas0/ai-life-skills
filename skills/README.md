# Skill Notes

Put one Markdown file here per Claude Skill.

## Naming

- Use lowercase hyphenated filenames when possible.
- File name should match the catalog entry slug.
- Example: `browser-automation.md`

## Required note fields

- Skill name
- What it does
- When to use it
- Official URL
- Source / repo URL if available
- Trigger phrases
- Setup / install notes
- Usage tips
- Caveats or gotchas
- Related skills

## Writing rules

- Put facts at the top.
- Put inferred details in a separate section or label them clearly.
- Keep the README index row short; keep details in the note file.
- If you know the official URL, include it in the index and the note.

## Template

Copy `skills/_template.md` for new entries.
