# variant

## Summary
Variant is an AI design exploration tool for generating endless app or website design options from a prompt by scrolling through variations.

## Aliases
- Variant
- variant.com
- variant ui

## When to use
- Exploring multiple UI/UX directions quickly from a rough product idea
- Getting app or website design inspiration before implementation
- Broad visual ideation when you want options more than prompt tinkering
- Comparing different interface moods, layouts, and styles early in the process
